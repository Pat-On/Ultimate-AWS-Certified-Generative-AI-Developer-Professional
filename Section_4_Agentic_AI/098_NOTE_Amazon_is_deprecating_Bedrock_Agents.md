# 98. NOTE: Amazon is deprecating Bedrock Agents

- **Effective July 30, 2026**, AWS is renaming **Amazon Bedrock Agents** to **Amazon Bedrock Agents Classic** and moving it to **maintenance mode**. As a result, you may not be able to follow along with the hands-on lab in the following lectures.
- **The exam guide has not been updated** with this development, and Bedrock Agents **remains in scope for the exam** for now. It is still important to understand how it works, and it is a very good way to learn the basics of agentic AI.
- AWS encourages new users to use **Amazon AgentCore** instead. It is covered later in this section.
