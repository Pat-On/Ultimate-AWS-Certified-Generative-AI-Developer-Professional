# 142. NOTE: Amazon is deprecating SageMaker Ground Truth, Model Monitor, and Clarify

- **Effective July 30, 2026**, AWS is moving several **SageMaker AI features to maintenance mode**: **Ground Truth, Model Monitor and Clarify**. They are **no longer available to new customers** from that date. Customers already using them can keep doing so, and AWS continues to operate and support them.
- **They remain in scope for the exam guide for now**, so it is still important to understand how they work.
- The announcement (posted **June 30, 2026**, see the AWS service availability page) lists more SageMaker AI features moving to maintenance: **A2I, Debugger, GeoSpatial, Mechanical Turk, Role Manager and Studio Lab**.
- Other changes in the same announcement:
  - **SageMaker AI Ground Truth Plus** reached **end of support** on June 30, 2026.
  - **SageMaker AI Profiler** is entering **sunset**, with a date to be announced.
  - Outside SageMaker: **Amazon Bedrock Agents** becomes **Bedrock Agents Classic**, and **Amazon Kendra**, **Amazon Q Business** and **Amazon Cognito Sync**, among others, also move to maintenance.
- AWS recommends reading the product pages and documentation for each affected service for migration advice and replacements, where there is one.

Source: <https://aws.amazon.com/about-aws/whats-new/2026/06/aws-service-availability/>
