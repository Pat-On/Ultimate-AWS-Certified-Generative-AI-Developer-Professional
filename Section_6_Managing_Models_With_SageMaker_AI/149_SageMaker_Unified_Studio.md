# 149. SageMaker Unified Studio

SageMaker grew over time and became fragmented: SageMaker Studio for notebooks, other UIs for everything else, and SageMaker AI as another thing. **SageMaker Unified Studio** is a **single interface for the whole data, analytics, AI and ML lifecycle**.

## What it brings together

- **Data processing and analytics**, **AI and ML** (build, deploy, execute, monitor), including **Bedrock, Amazon Q and QuickSight**.
- **Everything from the old SageMaker Studio**, such as Python notebooks.
- Built for **teams**: **administrators manage users and groups** and what they can access. A **domain connects assets, users and projects**.
- **Visual Studio Code integration**: connect securely over the web and develop AI and ML code in VS Code. It has built-in IDE support for **JupyterLab and VS Code**.

## What you can do from the left-hand menu

- **Notebooks** (a built-in Jupyter environment, with sample notebooks).
- **Workflows**, **query editors**, **visual ETL** and **data processing jobs** (roughly where Data Wrangler now lives).
- Track your **AI and ML models**, and integrate with **MLflow** for workflows.
- Watch **training jobs** (which can be costly) and the **inference endpoints** you have deployed.

## Exam takeaways

1. **Unified Studio** = one interface to **build, deploy, execute and monitor** data, analytics, AI and ML work, including Bedrock, Q and QuickSight.
2. It is built for **teams**: administrators manage users and groups, and a **domain** connects assets, users and projects.
3. It includes the **old SageMaker Studio** features and **VS Code** and **JupyterLab** IDEs, plus **MLflow** integration.
