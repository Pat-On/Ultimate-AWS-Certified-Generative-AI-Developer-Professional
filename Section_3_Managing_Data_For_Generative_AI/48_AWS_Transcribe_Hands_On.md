# 48. AWS Transcribe - Hands On

A short console demo of **Amazon Transcribe** real-time streaming.

- Create a transcript, set the language (English US) and choose start streaming. Spoken audio appears directly as text.
- **PII identification** setting: choose identify and redact, then pick which PII types to remove. In the test, a spoken name and phone number were hidden in the transcript.
- **Automatic language identification**: select multiple languages (English and French) and Transcribe recognised both while streaming.
- Further options are available at the bottom of the page.
