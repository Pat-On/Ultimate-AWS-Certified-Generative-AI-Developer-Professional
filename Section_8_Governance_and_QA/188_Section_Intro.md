# 188. Section Intro

**Governance and Quality Assurance:** the course moves from building generative AI systems to making sure they are **safe, reliable, governed and evaluated** in real use.

## Evaluation and governance

| Topic | Purpose |
|---|---|
| **Bedrock Prompt Management** | Central control, versioning and audit of prompts |
| **Bedrock Agent tracing** | See how agents reason, act and use tools |
| **Foundation model evaluation** | Accuracy, relevance, consistency and safety, manual and automated, including **Bedrock model evaluations** |
| **RAG evaluation** | Whether retrieval delivers the right context |
| **Deployment validation, responsible AI** | Test for **drift**, **hallucination** risk and **policy compliance** before and after launch |

## Observability and access

| Service | Role |
|---|---|
| **CloudWatch** metrics, logs, alarms | Model behaviour, latency, **token usage**, user interactions |
| **CloudTrail** | Track access and keep an **audit** trail |
| **X-Ray** | Trace foundation model calls end to end |
| **Lake Formation** | Govern access to the data behind models and vector stores |

The section also covers other AI monitoring tools.
