# 178. AWS WaveLength

**Wavelength Zones** are AWS infrastructure **inside telecom providers' data centres at the edge of 5G networks**, giving mobile users **ultra-low latency**.

- Run services such as **EC2, EBS and VPC** there, reached through a **carrier gateway**.
- Traffic can stay **inside the provider's network**.
- A high-bandwidth, secure link connects to the **parent Region**, for example for RDS or DynamoDB.
- The slides state **no additional charges or service agreements**.

**Use cases:** smart cities, ML-assisted diagnostics, connected vehicles, interactive live video, AR/VR, real-time gaming.

## Exam takeaway

**"5G" in the question usually means Wavelength.**
