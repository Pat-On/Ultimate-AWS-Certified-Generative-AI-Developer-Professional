# 182. AWS Amplify

**Amplify** is a set of tools to build and deploy **full-stack web and mobile applications**: think of it as **Elastic Beanstalk for web and mobile apps**.

1. **Backend** (Amplify CLI): uses S3, Cognito, AppSync, API Gateway, SageMaker, Lex, Lambda, DynamoDB and more.
2. **Features** configured in one place: authentication, storage, REST or GraphQL APIs, CI/CD, pub/sub, analytics, AI/ML predictions, monitoring.
3. **Source:** GitHub, CodeCommit, Bitbucket, GitLab or direct upload.
4. **Frontend libraries** connect web and mobile apps to the backend.
5. **Deploy** with the Amplify Console to Amplify and **CloudFront**.

**Correction:** the lecture calls Lex "text detection". **Amazon Lex** builds **conversational interfaces** (chatbots).

## Exam takeaway

**One-stop shop for web and mobile app development = Amplify.**
