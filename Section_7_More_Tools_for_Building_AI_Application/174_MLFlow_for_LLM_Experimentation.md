# 174. MLflow for LLM Experimentation

**MLflow** is a popular **open-source** platform for ML and generative AI workflows: **observability, evaluations, tracking, tracing**, an **AI gateway**, and **model management and deployment**.

It is available as a **fully managed** service integrated into **Amazon SageMaker AI**, so teams that know MLflow can keep using it as an alternative interface (similar in scope to tools such as SageMaker Pipelines). SageMaker provides the compute and storage; **artifacts go to your S3 buckets**.

**Integration points:** SageMaker Studio, Model Registry, SageMaker AI inference, **IAM**, **CloudTrail**, **EventBridge**.

## Exam takeaway

**MLflow = open-source ML/GenAI lifecycle platform, fully integrated with SageMaker AI.**
