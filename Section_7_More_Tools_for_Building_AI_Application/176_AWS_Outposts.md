# 176. AWS Outposts

**Hybrid cloud** means running on-premises and cloud together, normally with two sets of tools and skills. **Outposts** are **AWS server racks installed in your data centre**, offering the same infrastructure, services, APIs and tools as the cloud.

- AWS sets up and **manages** the racks.
- **You are responsible for their physical security.**

**Benefits:** low latency to on-premises systems, **local data processing**, **data residency**, an easier migration path to the cloud, fully managed.

**Services:** EC2, EBS, S3, EKS, ECS, RDS, EMR (among others).

## Exam takeaway

**AWS services on your premises**, for latency or data residency, means **Outposts**.
