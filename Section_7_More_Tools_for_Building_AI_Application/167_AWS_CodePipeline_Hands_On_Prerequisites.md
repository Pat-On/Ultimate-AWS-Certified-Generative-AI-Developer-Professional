# 167. AWS CodePipeline Hands On Prerequisites

- **Type:** Practice lab (setup)

Create the **Elastic Beanstalk** targets that the pipeline lab deploys to.

1. Create a **web server environment** in a new application (`MyFirstWebAppBeanstalk`): managed **Node.js** platform (latest), sample application, **single instance**, no key pair. Skip to review and submit.
2. In the same application, create a **second environment** called **prod** with the same settings.

**Clean up** both environments at the end of the section, because their EC2 instances cost money.
